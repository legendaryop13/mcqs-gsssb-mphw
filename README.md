# GSSSB MPHW (Male) Class-3 — Advt. 404/2025-26 — મહત્વના MCQ બેંક (ગુજરાતી)

**પરીક્ષા પેટર્ન (સત્તાવાર):**
- કુલ 210 પ્રશ્ન / 210 માર્ક્સ / 180 મિનિટ (CBRT/OMR)
- નેગેટિવ માર્કિંગ: દરેક ખોટા જવાબ માટે 0.25 ગુણ કપાશે
- Part-A: 90 પ્રશ્ન (પાસ થવા 36/90 = 40%)
- Part-B: 120 પ્રશ્ન (પાસ થવા 48/120 = 40%)
- બંને ભાગમાં **અલગ-અલગ** 40% ફરજિયાત

**ભૂતકાળના પેપર પરથી મળેલી ટ્રેન્ડ ટિપ્સ (GPSSB MPHW 26-06-2022, SMC MPHW 2023, GSSSB હેલ્થ પેપર્સ):**
1. સમિતિઓ (ભોરે, મુદલિયાર, ચાડા, મુખરજી, જંગલવાલા, કરતારસિંહ, શ્રીવાસ્તવ) + રાષ્ટ્રીય આરોગ્ય નીતિ/યોજનાઓ — દરેક પેપરમાં 10-15 પ્રશ્ન સીધા પુછાયા છે → સૌથી વધુ સ્કોરિંગ.
2. રોગોના કારક, વાહક (મચ્છર), રસીકરણ ડોઝ, રાષ્ટ્રીય કાર્યક્રમોનાં નામ — રિપીટ થાય છે.
3. જન્મ-મરણ નોંધણી અધિનિયમ 1969 (21 દિવસ, ફોર્મ, જવાબદારી) — નિયમિત પુછાય છે.
4. Part-A માં ગણિત + તર્ક ઝડપી બનાવો; બંધારણમાં મૂળ હકો/કલમ સૌથી વધુ પુછાય છે.
5. નેગેટિવ માર્કિંગ હોવાથી અંદાજે 30-35% પ્રશ્ન ગેરહાજર રાખવાનું ટાળો — ખાતરીવાળા જવાબ આપો.
